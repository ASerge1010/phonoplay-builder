# PhonoPlay Builder

PhonoPlay is a frontend web application created for Assessment 1: Frontend Design and Usability.

The application is designed for Speech Pathology teachers and students who want to create phoneme-based classroom activities.

## Features

- Home page with project overview
- About page with project information
- Phoneme-based Wordle activity
- Phoneme-based Word Search activity
- Light and dark theme settings
- Persistent theme preferences using cookies
- Responsive navigation and mobile hamburger menu
- Keyboard-accessible controls
- Mouse-over phoneme hints
- Standalone HTML generation for Wordle and Word Search

## Technology

- Next.js
- React
- TypeScript
- CSS
- Git and GitHub

## Assessment 1 Scope

Assessment 1 focuses on frontend design, usability, accessibility and responsive design.

The Wordle activity currently uses a single fixed phoneme-based target word.

The Word Search activity uses a small fixed list of phoneme-based words.

Database-driven word lists and more advanced content generation are intended for later assessments.
